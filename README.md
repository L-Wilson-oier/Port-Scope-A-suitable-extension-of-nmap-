# Port-Scope-A-suitable-extension-of-nmap-
PortScope: a read-only, protocol-aware post-Nmap port diagnostic tool. Validates TCP/UDP reachability, runs low-impact probes (HTTP/TLS/SSH/SMB/RDP/SQL/mail/DNS), flags protections, and suggests vulnerability areas. Includes a continuous --listen mode with spinner, pacing, and conflict checks.
